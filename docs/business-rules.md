# 코딩테스트 멘토링 플랫폼 도메인 설계

## 핵심 도메인

### User (사용자) 도메인

- 기본적인 회원 정보 (이메일, 비밀번호, 전화번호 등)
- 백준 ID 연동 정보
- 멘티/멘토 역할 구분
- solved.ac 티어 정보

### Mentoring (멘토링) 도메인

- 멘토링 포스트 (멘토가 작성하는 서비스 소개)
- 멘토링 예약/일정
- 멘토링 세션 정보
- 가격 정책

### Session (실시간 세션) 도메인

- 실시간 코드 에디터 데이터
- 음성 통화 기록
- 녹화 데이터
- 세션 상태 관리

### Payment (결제/정산) 도메인

- 결제 정보
- 멘토 수익 정산
- 환불 처리

## 도메인 간 주요 연관관계

User ↔ Mentoring: 멘토/멘티는 각각 멘토링을 제공/신청
Mentoring ↔ Session: 예약된 멘토링은 실시간 세션으로 진행
Mentoring ↔ Payment: 멘토링 예약 시 결제 발생

## 회원가입 프로세스 규칙

하나의 페이지에서 상태를 통해 단계 관리

### 일반 회원가입 (멘티)

1. 이메일 입력
2. 이메일 인증
3. 약관 동의
4. 사용자 ID입력
5. 비밀번호 입력
6. 프로필 작성

### solved.ac API를 통한 백준 ID 검증 및 연동

1. 백준 ID 입력후 인증하기 버튼 클릭
2. 사용자에게 “사용자 프로필을 다음 문자열로 수정해주세요” 문구와 함께 `랜덤 문자열`(카카오뱅크 입금 느낌 ex. 배부른고양이223)과 [`solvedac 프로필 수정](https://solved.ac/settings/profile) 링크`그리고`“인증하기” 버튼`을 화면에 제공
3. 사용자는 프로필을 수정하고 인증하기 버튼을 눌러 인증을 요청
4. 서버는 사용자 핸들로 부가 정보 가져오기 API로 프로필 이름을 조회해 문자열이 일치하면 인증을 완료
5. 일치하지 않으면 인증 실패

#### solved.ac 연동 후 프로세스

멘토 제안 조건: solved.ac 티어 플래티넘 3이상

- 등급 미달: 일반 사용자로 완료
- 등급 충족: 멘토 전환 제안
- 티어 정보 연동 및 저장

#### 초기 연동 시점

백준 ID 검증 완료 시점

#### 멘토 자격 심사 시점

- 사용자의 수동 갱신 요청 시점 (하루 N회 제한, solvedac 측의 429응답)
- 티어 정보 저장

#### DB에 저장할 사용자 티어 정보

- 현`재 티어
- 최근 갱신 일시
- 최고 달성 티어
- 문제 풀이 이력은 최근 3개월 분량만 저장
- 플래티넘 5 이상 문제 풀이 여부 확인용
- 증분 업데이트로 관리
- 티어 정보 표시

#### 사용자 프로필 표시 정보

- 현재 티어
- 마지막 갱신 일시
- 티어 정보 갱신 버튼

#### 캐싱 정책

- 프로필 페이지 정보: 24시간 캐싱

### 멘토 전환 프로세스

사전 조건: solved.ac 티어 충족

1. 멘토 전환 수락
2. 멘토 프로필 정보 입력
3. 관리자의 멘토 정보 검증
4. 멘토 전환 완료
5. 도용 방지: 연구 필요 solved.ac API로 검증 불가, 백준 크롤링 불가, 백준에 등록한 이메일 확인 불가.

### 멘토 자격 기준

**solved.ac 기준**

1. 필수 조건

- 플래티넘 3 이상
- 최근 3개월 내 플래티넘 5 이상 문제 풀이 이력
- 회사 메일 인증 필요(미봉책)

#### 추가 고려사항:

- 백준 프로필이 공개되어 있어야 함
- 멘토 신청 시점 기준으로 검증

#### 멘토 등록 시 필요 정보

- 백준 ID
- solved.ac 프로필 링크
- 회사 이메일
- 검증 방식
- 백준 ID 기반 solved.ac API 호출
- 현재 티어 확인
- 최근 3개월 플래티넘 5 이상 문제 풀이 이력 확인
- 프로필 정보 중 회사 이메일 인증
- 관리자 최종 승인

#### 멘토 프로필 관리

- 기본 정보 (필수)
- 프로필 이미지 (선택)
- 실명 (필수)
- 직무 정보 (회사명 BE, FE, …)
- 현재 직무 상태 (현직)
- 희망 멘토링 분야 (백엔드/프론트엔드/알고리즘)
- 경력 기간 (신입/1-3년/3-5년/5년 이상)
- 자기소개 (최소 200자)
