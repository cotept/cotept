# **코딩테스트 멘토링 플랫폼 도메인 설계**

## **핵심 도메인**

### **User (사용자) 도메인**

- 기본적인 회원 정보 (이메일, 비밀번호, 전화번호 등)
- 백준 ID 연동 정보
- 멘티/멘토 역할 구분
- [solved.ac](http://solved.ac/) 티어 정보

### **Mentoring (멘토링) 도메인**

- 멘토링 포스트 (멘토가 작성하는 서비스 소개)
- 멘토링 예약/일정
- 멘토링 세션 정보
- 가격 정책

### **Session (실시간 세션) 도메인**

- 실시간 코드 에디터 데이터
- 음성 통화 기록
- 녹화 데이터
- 세션 상태 관리

### **Payment (결제/정산) 도메인**

- 결제 정보
- 멘토 수익 정산
- 환불 처리

## **도메인 간 주요 연관관계**

1. User ↔ Mentoring: 멘토/멘티는 각각 멘토링을 제공/신청
2. Mentoring ↔ Session: 예약된 멘토링은 실시간 세션으로 진행
3. Mentoring ↔ Payment: 멘토링 예약 시 결제 발생

## **회원가입 프로세스 규칙**

하나의 페이지에서 상태를 통해 단계 관리

### **일반 회원가입 (멘티)**

1. 본인 인증 (휴대폰)
2. 기본 정보 입력 (이메일, 비밀번호,이메일 인증)
3. 약관 동의
4. 가입 완료

### **백준 ID 입력 프로세스**

1. 백준 ID 입력
2. 백준 ID 검증
   - 가장 최근에 푼 문제가 몇번인지 선택하기

   최근에 푼 3가지 문제 번호를 가져와 라디오 버튼으로 선택

   장점: UX 우수

   단점: 백준ID 검색하면 최근에 푼 문제가 다 보인다.
   - 최근 푼 문제를 볼 수 있는 백준 링크를 삽입한다.
   - ~~가장 최근에 푼 문제를 다시 한번 풀기~~
   - ~~이미 풀었던 문제 중에 특정 문제를 다시 풀게 하기(대리를 못막음)~~

3. [solved.ac](http://solved.ac/) 티어 확인
   - 등급 미달: 일반 사용자로 완료
   - 등급 충족: 멘토 전환 제안
4. 티어 정보 연동 및 저장
   - 초기 연동 시점
     - 백준 ID 검증 완료 시점
     - 멘토 자격 심사 시점
     - 사용자의 수동 갱신 요청 시점 (하루 N회 제한, solvedac 측의 429응답)
   - 티어 정보 저장
     - 사용자 DB에 티어 정보 저장
       - 현재 티어
       - 최근 갱신 일시
       - 최고 달성 티어
     - 문제 풀이 이력은 최근 3개월 분량만 저장
       - 플래티넘 5 이상 문제 풀이 여부 확인용
       - 증분 업데이트로 관리
5. 티어 정보 표시
   - 프로필 표시 정보
   - 현재 티어
   - 마지막 갱신 일시
   - 티어 정보 갱신 버튼
6. 캐싱 정책
   - 프로필 페이지 정보: 24시간 캐싱

### **멘토 전환 프로세스**

- [solved.ac](http://solved.ac/) 티어 충족
- 멘토 전환 수락

1. 멘토 프로필 정보 입력
2. 관리자의 멘토 정보 검증
3. 멘토 전환 완료

- 도용 방지: **연구 필요
  solved.ac API로 검증 불가
  백준 크롤링 불가
  백준에 등록한 이메일 확인 불가**

## **멘토 자격 기준**

### [\*\*solved.ac](http://solved.ac/) 기준\*\*

필수 조건

- 플래티넘 3 이상
- 최근 3개월 내 플래티넘 5 이상 문제 풀이 이력
- 회사 메일 인증 필요(미봉책)

추가 고려사항:

- 백준 프로필이 공개되어 있어야 함
- 멘토 신청 시점 기준으로 검증

### **멘토 등록 시 필요 정보**

1. 백준 ID
2. [solved.ac](http://solved.ac/) 프로필 링크
3. 회사 이메일

### **검증 방식**

1. 백준 ID 기반 [solved.ac](http://solved.ac/) API 호출

- 현재 티어 확인
- 최근 3개월 플래티넘 5 이상 문제 풀이 이력 확인

2. 프로필 정보 중 회사 이메일 인증
3. 관리자 최종 승인

## **멘토 프로필 관리**

### **기본 정보 (필수)**

- 프로필 이미지 (선택)
- 실명 (필수)
- 직무 정보 (회사명 BE, FE, …)
- 현재 직무 상태 (현직)
- 희망 멘토링 분야 (백엔드/프론트엔드/알고리즘)
- 경력 기간 (신입/1-3년/3-5년/5년 이상)
- 자기소개 (최소 200자)

### **멘토링 가능 시간 관리**

- 기본 설정 KST
- 가능한 요일 선택
- 시간 슬롯 설정
  - 최소 단위: 70분
  - 기본값: 70분
    - 준비 시간 5분
    - 휴식 시간 5분
- 요일별 반복 설정 가능
- 특정 날짜 예외 처리 가능

### **멘토링 정보 (필수)**

- 멘토링 가능 시간
- 시간대별 가능 여부
- 세션당 멘토링 비용

### **추가 정보 (선택)**

- 깃허브 프로필
- 블로그 주소
- 합격한 기업 코딩테스트 목록
- 수상 이력
- 기타 자격증/인증

### **멘토링** 가능 **시간 슬롯 설정 정책**

- 최대 설정 가능 기간: 4주
  - 이유: 멘토의 장기 스케줄 관리와 멘티의 계획적인 예약 기회 제공
  - 너무 긴 기간은 멘토의 상황 변화로 인한 취소 위험 증가
- 최소 설정 필요 기간: 3일
  - 이유: 멘티들의 예약 기회 보장
  - 갑작스러운 슬롯 추가로 인한 혼란 방지

### **휴식 시간 정책**

- 전환 시간: 각 세션 전후 5분

### 슬롯 변경/취소 기준

- 예약 없는 슬롯
  24시간 전까지 자유롭게 변경 가능
- 예약된 세션이 있는 경우
  - 72시간 전까지: 페널티 없이 변경 가능
  - 72~24시간 전: 경고 1회 부여 및 취소한 멘토링 수익 회수
  - 24시간 미만: 경고 1회 부여 및 취소한 멘토링 수익 회수, 1달간 수익 페널티 20%
  - 경고 3회 누적 시 멘토 자격 일시 정지 및 7일 동안 무소명 시 블랙리스트 등록
- 불가항력적 상황 (질병, 사고 등)
  - 증빙 자료 제출 시 페널티 면제
  - 멘티에게 대체 멘토 또는 100% 환불 제공

## **세션 진행 정책**

멘토의 경우 70분 전후 5분 휴식 및 준비 시간
멘티의 경우 60분

- 세션 시간: 60분 고정
  - 입장 및 환경 체크: 5분
  - 실제 멘토링: 50분
  - 피드백 및 마무리: 5분
- 입장 규칙
  - 세션 시작 5분 전부터 입장 가능
  - 세션룸 사전 테스트 기능 제공 (음성)
- 지각 및 불참 규칙
  - 멘티 지각
    - 시작 시간 10분까지 대기
    - 10분 초과 시 자동 취소
    - 환불 불가
  - 멘토 지각
    - 10분 이상 지각 시 멘티가 취소 가능
    - 취소 시 멘티 전액 환불 및 멘토 경고 1회
- 중단 상황 처리
  - 기술적 문제 발생 시
    - 15분 이내 복구: 해당 시간만큼 세션 연장
    - 15분 초과: 멘티 선택권 부여
      - 남은 시간만큼 재예약
      - 또는 남은 시간 비율만큼 환불
  - 불가항력적 상황 (정전, 자연재해 등)
    - 양측 페널티 없음
    - 전액 환불 또는 전체 재예약

### **6.5 운영 시간 정책**

- 시스템 운영 시간
  - 평일/주말 동일: 08:00 ~ 23:00
  - 첫 타임 슬롯: 08:00 - 09:1
  - 마지막 타임 슬롯: 21:40 - 22:50
- 일일 전체 타임 슬롯
  - 70분 단위 (60분 세션 + 10분 휴식)
  - 하루 총 13개 슬롯
  - 세션 종료 후 10분은 자동으로 전환 시간으로 할당
    - 멘토: 다음 세션 준비
    - 시스템: 세션 데이터 정리 및 저장
- 멘토 스케줄 관리
  - 가능 시간 설정
    - 멘토 프로필/대시보드에서 관리
    - 요일별 선호 시간대 설정 가능
    - 일회성 또는 정기적 설정 가능
  - 스케줄 템플릿 기능
    - 주간 단위 반복 설정
    - 특정 날짜 예외 처리
    - 휴가/부재 기간 설정
- 시스템 마감 처리
  - 마지막 세션 종료: 22:50
  - 정산 처리 시작: 23:00
  - 다음날 은행 영업시간에 정산 완료

### **예약 프로세스 방식**

실시간 슬롯 예약 (Pick & Pay)

1. 멘티: 원하는 타임 슬롯 직접 선택
2. 시스템: 선택 슬롯 10분간 임시 홀드
3. 멘티: 10분 내 결제 진행
   - 단건 결제
   - 또는 보유 패키지 크레딧 사용
4. 시스템: 예약 확정 및 멘토 멘티 알림

선착순 결제 후 슬롯 선택 (Pay First)

1. 멘티: 단건 멘토링 결제 진행
2. 시스템: 결제 완료 순서대로 예약 순번 부여
3. 멘티: 순번에 따라 원하는 슬롯 선택
4. 시스템: 예약 확정 및 멘토 알림

### **결제 유형**

- 단건 결제

### **불가항력 상황 처리**

- 인정 범위
  - 의료: 입원/응급실 진단서
  - 사고: 경찰서 신고서, 보험 청구서
  - 직계가족 상: 사망진단서
- 처리 절차
  - 증빙 제출: 상황 발생 48시간 이내
  - 검토 완료: 제출 후 24시간 이내
- 증빙자료 처리
  - 접수 방법
    - 암호화된 전송 채널 사용 (HTTPS)
    - 임시 업로드 링크 발급 (1회용)
  - 저장 정책
    - 개인정보 마스킹 처리 필수
      - 주민번호 뒷자리
      - 상세 주소
      - 연락처
    - 암호화 저장 (AES-256)
    - 보관 기간: 검토 완료 후 즉시 삭제
    - 증빙 승인 여부만 DB에 기록
  - 열람 권한
    - 담당 관리자만 열람 가능
    - 열람 이력 기록

### **신뢰도 평가 시스템**

기본 신뢰도

- 멘토 신뢰도
  - 기본 시작: 36.5도
  - 범위: 0도 ~ 45도
  - 측정 요소:
    - 세션 완료율 (+0.5도)
    - 시간 준수율 (+0.3도)
    - 피드백 반영률 (+0.2도)
    - 무단 취소 (-2.0도)
    - 지각 (-1.0도)
    - 불만 신고 (-1.5도)
- 멘티 신뢰도
  - 기본 시작: 36.5도
  - 범위: 0도 ~ 45도
  - 측정 요소:
    - 세션 완료 (+0.5도)
    - 시간 준수 (+0.3도)
    - 무단 불참 (-2.0도)
    - 지각 (-1.0도)
    - 악의적 리뷰 (-1.5도)

평가 시스템

- 평점 산정 방식
  - 최근 10회 세션 기준
  - 최고점과 최저점 각각 1개 제외
  - 나머지 8개 평점의 산술 평균 적용

이의제기 프로세스

- 신청 조건
  - 신뢰도 변동 후 7일 이내
  - 구체적인 사유와 증빙자료 필수
- 처리 절차
  - 접수 후 48시간 내 1차 검토
  - 필요시 상대방 의견 청취
  - 최종 결정까지 최대 7일 소요
- 결과 처리
  - 인용: 신뢰도 즉시 복구
  - 기각: 현재 신뢰도 유지
  - 부분 인용: 감점 일부 복구

## 리뷰 및 신뢰도 시스템

### 멘토링 세션 리뷰 시스템

### 멘티 리뷰

- 작성 자격: 정상 종료된 세션의 참여 멘티
- 작성 제한: 세션당 1개 리뷰
- 수정 기한: 작성 후 1시간 이내
- 리뷰 구성
  - 별점 (필수)
  - 코멘트 (선택, 10자~300자)

### 멘토 답글

- 작성 자격: 해당 세션의 담당 멘토
- 작성 제한: 리뷰당 1개 답글
- 수정 기한: 작성 후 1시간 이내
- 답글 제한: 10자~300자

### 멘토 신뢰도(온도) 시스템

### 기본 규칙

- 시작 온도: 36.5도
- 범위: 0도 ~ 45도

### 멘토링 리뷰 별점 기반 멘토 온도 변화

- 5점: +0.5도
- 4점: +0.3도
- 3점: 변화 없음
- 2점: -0.2도
- 1점: -0.4도

### 온도 변화 규칙

- 연속 5점 10회 이상: 추가 상승폭 50% 감소

### 리뷰 시스템 운영 정책

### 리뷰 작성 시점

- 세션 정상 종료 직후부터 작성 가능
- 'COMPLETED' 상태의 세션만 리뷰 작성 가능

### 시스템적 제한사항

- 이미 리뷰를 작성한 세션은 리뷰 버튼 비활성화
- 수정 가능 시간(1시간) 이후 수정 버튼 자동 제거
- 한 세션당 하나의 리뷰만 허용

## 멘티 → 멘토 피드백 (필수)

### A. 사전 준비도 (5점 척도)

평가 기준

- 5점: 멘티의 백준 프로필을 분석하여 맞춤형 학습 계획이 준비되어 있음
- 4점: 멘티의 현재 수준에 맞는 문제와 설명 자료가 준비되어 있음
- 3점: 기본적인 설명 자료만 준비되어 있음
- 2점: 최소한의 준비만 되어 있음
- 1점: 특별한 준비 없이 즉흥적으로 진행

### B. 설명의 명확성 (5점 척도)

평가 기준

- 5점: 복잡한 개념을 쉽게 이해할 수 있게 설명하고, 적절한 예시를 제공함
- 4점: 개념을 논리적으로 설명하고 질문에 명확히 답변함
- 3점: 기본적인 설명은 제공하나 깊이 있는 설명이 부족함
- 2점: 설명이 불명확하거나 이해하기 어려움
- 1점: 설명이 매우 부족하거나 잘못된 정보를 제공함

### C. 문제 해결 도움도 (5점 척도)

평가 기준

- 5점: 문제 해결 방향을 명확히 제시하고, 실제 코드 작성까지 체계적으로 지도
- 4점: 문제 해결을 위한 접근 방법을 잘 설명하고 힌트를 적절히 제공
- 3점: 기본적인 문제 해결 방향은 제시하나 구체적 방법론 설명이 부족
- 2점: 문제 해결에 대한 도움이 제한적임
- 1점: 문제 해결에 실질적인 도움이 되지 않음

## 세션 운영 정책

### 세션 시간 구성

- 전체 슬롯 시간: 75분
- 멘토링 세션: 60분 (고정)
- 전환 시간: 15분
  - 사전 준비: 5분 (멘토 입장, 환경 점검)
  - 여유 버퍼: 5분 (장애 대응용)
  - 정리 시간: 5분 (다음 세션 준비)
- 시간표 예시
- 10:00-10:05: 멘토 입장 및 준비
- 10:05-10:10: 멘티 입장 및 녹화 시작
- 10:10-11:10: 멘토링 세션 진행
- 11:10-11:15: 정리 및 전환

### 녹화 시간 정책

- 녹화 시작
- 시작 시점: 멘티 입장 시
- 사전 준비 시간은 녹화하지 않음
- 녹화 종료
- 정상 종료: 세션 시작 후 60분 경과 시
- 조기 종료: 세션 종료 버튼 클릭 시
- 강제 종료: 세션 시작 후 65분 경과 시 (버퍼 5분 포함)
- 녹화 시간 제한
- 최소 녹화 시간: 없음
- 최대 녹화 시간: 65분
- 녹화 분할: 단일 파일로 저장 (분할 없음)

### 장애 상황 처리

- 5분 이내 장애
- 버퍼 시간 내에서 자동 연장
- 다음 세션 영향 없음
- 5분 초과 장애
- 정시 종료 후 크레딧 보상
- 다음 세션 정상 진행

### 조기 종료 정책

- 자발적 조기 종료 (멘토/멘티 합의)
- 학습 목표 조기 달성
- 녹화 즉시 종료
- 전체 비용 청구 (환불 없음)
- 다음 세션은 정시 시작
- 멘티 요청 조기 종료
- 개인 사유로 인한 종료:
  - 전체 비용 청구
  - 환불 불가
- 멘토 부적절 행위로 인한 종료:
  - 즉시 환불 처리
  - 멘토 패널티 부과
  - 관리자 조사 진행
- 멘토 요청 조기 종료
- 불가항력적 상황 (긴급 사유):
  - 전액 환불
  - 보상 크레딧 30분 추가 지급
- 기술적 문제로 인한 종료:
  - 전액 환불
  - 다른 멘토 매칭 제안

## VOD 서비스 정책

### 녹화 파일 처리

- 진행된 시간만큼 저장
- 조기 종료 사유 메타데이터 기록
- 멘티에게 즉시 다운로드 권한 부여

### 인코딩 정책

- 코덱 선택: 테스트 기간 동안 유동적 적용
- 테스트 대상:
- H.264 vs VP8 vs VP9
- AAC vs Opus
- 평가 기준:
- 파일 크기
- 화질 품질
- 브라우저 호환성
- 트랜스코딩 속도
- 스토리지/네트워크 비용

### 업로드 정책

- 멀티파트 업로드 설정
- 기본 청크 크기: 2MB
- 최소 청크 크기: 512KB
- 최대 청크 크기: 5MB
- 동시 업로드 청크 수: 3개
- 재시도 정책
- 청크별 최대 재시도 횟수: 3회
- 재시도 간격: 지수 백오프 (1초, 2초, 4초)
- 세션 유효 시간: 24시간
- 업로드 실패 대응
- 일시적 네트워크 오류:
  - 자동 재시도 수행
  - 실패한 청크만 선택적 재업로드
- 브라우저 종료/크래시:
  - 업로드 진행 상태 로컬 저장
  - 재접속 시 이어서 업로드
- 세션 만료:
  - 새로운 세션 ID 발급
  - 이전 업로드 상태 복구

### 스토리지 계층화 전략

- Standard Storage (Hot Storage)
- 최근 7일 이내 녹화된 VOD
- 빠른 접근이 필요한 인기 컨텐츠
- 실시간 트랜스코딩된 파일의 임시 저장
- Infrequent Access Storage
- 7-30일 사이의 VOD 컨텐츠
- 중간 단계의 접근성과 비용 절감 효과
- 실시간 접근은 가능하나 접근 빈도가 낮은 컨텐츠
- Archive Storage (Cold Storage)
- 30일 이상 된 VOD 컨텐츠
- 장기 보관이 필요한 컨텐츠
- 거의 접근하지 않는 컨텐츠의 비용 효율적 보관

### 데이터 수명주기 관리

- 자동 이관 정책
- Standard → Infrequent: 업로드 후 7일 경과
- Infrequent → Archive: 마지막 접근 후 30일 경과
- 예상 월 비용: $15.00 (약 21,000원) per 1TB
- 예외 처리 정책
- 프리미엄 구독자의 컨텐츠: Standard Storage 유지
- 매출 상위 20% 멘토의 컨텐츠: 90일간 Infrequent Storage 유지
- 관리자가 지정한 우수 컨텐츠: Storage 등급 수동 관리
